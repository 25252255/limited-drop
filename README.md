## 선착순 상품 구매 상황에서 발생 가능한 *대규모 트래픽 및 동시성 문제* 해결을 목표로 구현

### 핵심 문제
- 대규모 동시 요청 발생 시 재고 데이터 정합성 문제
- DB 집중 부하로 인한 서비스 가용성 저하
- 사용자 대기 순번 조회를 위한 반복 요청
- 특정 서비스 장애 발생 시 전체 서비스 장애 전파 가능성

### 해결 방식
- 서비스 간 결합도 낮춘 구조와 Resilience4j을 통한 장애 전파 방지
- WebFlux를 통해 비동기로 대량 사용자 요청을 Redis ZSet 대기열에 등록
- SSE 연결을 통해 사용자에게 실시간 대기 순번 정보 제공
- Lua Script 기반 재고 차감 처리로 연산 원자성 보장
- Scheduler, TTL로 사용자 권한 관리

### 개발 환경
- Java 17, Lua Script
- Tomcat, Netty
- Spring Boot 3.5.13, MySQL 9.6.0 
- Git, Postman
